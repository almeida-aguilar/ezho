# ezho

Ezho is an echo clone made in Zig.

# Why did I make Ezho?

'Cause I can. Seriously, I just wanted to learn to program in Zig, and echo was the simplest tool out there, I guess.

# How to use it?

It's just like echo, but... it formats by default. That's the only change; otherwise, the -n, -e, and -E flags are the same.

# Is it better than echo?

I have no idea, I haven't tested it, and Ezho wasn't made to replace echo—I'm not a Rust dev. It's just a learning tool that clearly could be improved.
